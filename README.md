# GENS devlog

Static site for GitHub Pages (no build step). Open `index.html` in a browser to preview.

- Look: every colour/font is a token at the top of `assets/style.css`.
- New post: copy `posts/<last>.html`, put images (max 1600 px JPEG) in `img/<date>/`, add a card at the top of `.posts` in `index.html`.
- Both languages: every text block exists twice, with `lang="sk"` and `lang="en"`; `assets/lang.js` shows one.
