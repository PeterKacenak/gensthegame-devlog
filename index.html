Od kocky k dedineFrom a cube to a village

Prototyp, dom, postavy, krčma a dedina Honce: zhrnutie doterajšieho vývoja.

Prototype, house, characters, the pub and the village of Honce: a summary so far.

O hreAbout

Chcel som si zahrať hru zo slovenskej dediny. Takú som nenašiel, tak som sa rozhodol spraviť ju. Je to hra z pohľadu prvej osoby a odohráva sa v Honciach pri Rožňave. Sem si zapisujem, ako postupuje.I wanted to play a game set in a Slovak village. I couldn't find one, so I decided to make it. It's a first-person game set in Honce near Rožňava. This is where I write down how it's going.
